# Multimodal Construction Intelligence Platform

Skill Wallet Capstone Project 1 - an AI-assisted Streamlit dashboard for construction sites.

## Project Overview
The platform analyses construction-site photos with Google Gemini (multimodal), checks PPE compliance, diagnoses
concrete/wall cracks, estimates project budget and asset value in INR, gives weather-aware safety advisories and
provides a construction Q&A assistant. **It works fully without an API key in Demo Mode.**

## Problem Statement
Site safety checks, defect triage and early-stage budgeting are slow, manual and depend on scarce expertise.
Supervisors need a fast first-pass tool that is clearly labelled as assistive, not a replacement for professionals.

## Objectives
- Detect PPE use and visible hazards from an image and score site safety.
- Classify visible cracks and suggest causes and repairs.
- Produce conceptual budget, valuation and material estimates in INR.
- Provide weather-aware advisories and a construction chatbot.
- Return predictable, validated JSON for every AI output, with graceful fallbacks.

## Features
- **Site Safety & PPE Audit** - score, overall status, 4-item PPE checklist with confidence, hazard cards with severity badges, recommendations, JSON download.
- **Crack Diagnostics** - 5 defect classes, severity, width estimate, root causes, repairs (e.g. epoxy injection, structural re-grouting), urgency, confidence, JSON download.
- **Planning & Valuation** - budget, capex incurred, market asset valuation, steel and cement quantities, milestone progress, budget chart, JSON download; conceptual architectural rendering **prompt** generator.
- **Daily Site Assistant** - 4 weather conditions (alerts, actions, prohibited activities, checklist) and a chatbot.
- **Project Report** - one consolidated JSON for the whole session.
- **Demo Mode** - every feature works offline; demo output is always labelled *"Demonstration result - not generated by live AI."*

## Technology Stack
Python 3.9+ (tested on 3.12), Streamlit, google-genai (Gemini), Pillow, Pandas, Plotly, standard library `json`.

## System Architecture
```
Upload -> image validation (Pillow) -> GeminiService (live) --+
                                     \-> demo engine (offline) -+-> JSON extract/repair -> field validation -> UI + JSON report
```
No database. Temporary state lives in `st.session_state`. If Gemini fails (bad key, quota, network, malformed JSON) the app
shows a friendly warning and falls back to labelled demonstration data - it never crashes.

## Environment Variables
| Variable | Purpose |
|---|---|
| `GEMINI_API_KEY` | Optional. Enables live AI. Leave unset for Demo Mode. |
| `GEMINI_MODEL` | Optional. Default `gemini-2.5-flash`. |

Copy `.env.example` to `.env` if you like, then export the variable in your shell (the app reads the environment, it does not parse `.env` itself):
```bash
export GEMINI_API_KEY="your-key"      # Windows PowerShell: $env:GEMINI_API_KEY="your-key"
```
> **Do not commit API keys.** `.env` and `.streamlit/secrets.toml` are git-ignored. Never paste a key into source code, an issue or a screenshot.

## Demo Mode
With no key the sidebar shows **Demo Mode Active**. You can still upload images, run both analyses, calculate valuations,
use the weather advisor, chat and download JSON. Demo analyses require an uploaded image (nothing is produced without one) but the
findings are sample scenarios chosen from the image's hash - **they do not reflect what is actually in your photo** and are labelled as such.

## Gemini API Configuration
1. Create a key in Google AI Studio (https://aistudio.google.com/apikey).
2. Either paste it into the sidebar (**Activate live AI**; the box clears after submission and the key is never shown again), set `GEMINI_API_KEY`, or use Streamlit secrets when deployed.
3. The key is held only in server memory for your session. The app does not verify it up front; an invalid key is reported on first use and the app falls back to demo data.

## How Each Module Works
- **Safety (`safety_analysis.py`)** sends the image plus a prompt citing OSHA 29 CFR 1926 and IS standards, requests JSON, validates it (score 0-100, severities Low/Medium/High/Critical, PPE status Detected/Not Detected/Unclear). Items that are not visible should be reported "Unclear".
- **Crack (`crack_analysis.py`)** same pipeline for Hairline / Settlement / Structural Shear / Thermal Expansion / Spalling.
- **Valuation (`valuation.py`)** rule-of-thumb rates by structure type, location tier and finish quality. Budget = area x rate; capex = budget x completion; current asset value = completed share of value-at-completion + optional land; steel and cement from kg/sq ft and bags/sq ft factors. Rates are illustrative assumptions, not market data.
- **Rendering prompt** builds a text-to-image prompt only. No image-generation API is integrated.
- **Weather (`weather_advisor.py`)** fixed, reviewable advisories per condition.
- **Assistant (`construction_assistant.py`)** Gemini with site context, or a keyword knowledge base offline.

## JSON Output
Both vision modules return exactly the contracts in the specification. Every downloaded report wraps the result:
```json
{
  "report_type": "ppe_safety_audit",
  "generated_at": "2026-10-25T11:00:00+00:00",
  "result_source": "demonstration data",
  "demonstration_notice": "Demonstration result — not generated by live AI.",
  "source_file": "site.png",
  "disclaimer": "...",
  "result": { "safety_score": 64, "overall_status": "Partial Compliance", "ppe_detection": {}, "hazards": [], "recommendations": [] }
}
```
Parsing pipeline: strip code fences -> extract first JSON object -> repair (trailing commas, smart quotes, truncation) -> validate/clamp fields -> otherwise fall back to demo data.

## Deployment to Streamlit Community Cloud
1. Create a new empty repository on GitHub (e.g. `multimodal-construction-intelligence`), no README.
2. In the project folder:
```bash
git init
git add .
git commit -m "Initial commit: Multimodal Construction Intelligence Platform"
git branch -M main
git remote add origin https://github.com/<your-username>/multimodal-construction-intelligence.git
git push -u origin main
```
3. Open https://share.streamlit.io and sign in with GitHub.
4. Click **Create app** -> **Deploy a public app from GitHub** and authorise access.
5. Choose your repository, branch **main**, main file **app.py**.
6. Open **Advanced settings -> Secrets** and add (optional - skip for Demo Mode):
```toml
GEMINI_API_KEY = "your-gemini-api-key-here"
```
7. Click **Deploy**. Wait for dependencies to install.
8. Verify the HTTPS URL (`https://<app-name>.streamlit.app`): the sidebar should show *Live AI* with a key or *Demo Mode Active* without one, and every page should load.

## Testing
```bash
pip install pytest
python -m pytest -q
```
42 automated tests cover JSON repair, contracts, fallbacks, valuation maths and validation, weather, chatbot, image validation, and headless UI flows (every page, upload, analysis, planning, chat, invalid key).
**Not covered automatically:** calls to the real Gemini API with a valid key, visual layout in a real browser, and an actual Streamlit Cloud deployment. Test those manually.

Manual checklist: start without a key -> banner shows; upload a PNG on each vision page and run it; download each JSON; change valuation inputs; switch weather; ask the 3 example questions; upload a text file renamed `.jpg` (error message, no crash); paste a wrong key and run an analysis (warning + demo data).

## Limitations
- Gemini accuracy is not guaranteed; PPE and crack findings can be wrong. Crack width has no scale reference.
- Demo results are sample data, not image analysis.
- Valuation uses simplified national-average style rates and ignores land price variation, GST, labour, and regional rates.
- Architectural rendering is a prompt only; no image is generated.
- No persistence: refreshing the page clears results. Free-tier Gemini quotas apply.

## Future Enhancements

## Disclaimer
All outputs are AI-assisted or conceptual and are **not** a professional safety certification, structural inspection, bill of quantities or certified valuation. Consult qualified safety officers, structural engineers and registered valuers before acting.
